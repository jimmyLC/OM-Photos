## Import all new items

With nothing selected, the bottom bar shows "**Import All New Items (N)**", where N is how many you have not imported yet. Click it to start.

## Import only some photos

1. Select the photos you want (⌘-click, Shift-click for a range).
2. Click **Import** (匯入) at the bottom, or right-click a photo and choose "Import".

In the full-size view, "Import" imports just that photo.

## Choose a folder

Before each import, OM Photos asks for a folder and shows how many items, the total size and the estimated time. It starts at the folder you used last.

- Files go **straight into the folder you choose**; OM Photos never creates folders on its own.
- If a different file with the same name is already there, the new one is renamed to "name (1)". **Nothing is overwritten.**
- Creation and modification dates are set to the capture time, so sorting by date in Finder matches the shooting order.

To import into the Photos app instead, set "Import to" (匯入到) to "Photos Library" (照片圖庫) in Settings › Import. RAW+JPG pairs become one photo there.

## Order and progress

- Photos come first and videos last, so you see your photos sooner.
- The bottom bar shows the item number, file name, percentage and time left. You can cancel at any time.
- Every file is checked for size after downloading and retried once if it does not match. Files that still fail are listed, with a Retry button.
- Your Mac does not go to sleep while importing.

## Never twice

OM Photos remembers what you imported. Even if you move the files elsewhere, "Import All New Items" will not fetch them again; select them and import manually if you need another copy.

Imported photos have a green arrow on the thumbnail, and the Imported / Not imported filter shows them.

## Automatic import

Turn on "Import new items when the camera connects" (連上相機就自動匯入新項目) in Settings › Import to start importing as soon as you connect (to the folder you used last). It is off by default.

## Wi-Fi or USB?

| | Wi-Fi | USB-C |
|---|---|---|
| Speed (measured) | about 3 MB/s | about 35–45 MB/s |
| One-minute 4K video (about 640 MB) | about 3.5 minutes | about 15–20 seconds |

Wi-Fi is handy for a few photos; for videos or a full card, [use USB-C](/en/guide/usb/).
